Interact with the Preview

This is a 1:1 representation of how your UI will look in-game. Try interacting with it:

  • Click toggles to switch them on/off
  • Click and drag sliders to change values
  • Click dropdowns to cycle through options
  • Click buttons to see the press animation
  • Switch between tabs at the top

💡 All animations match exactly what players see in-game. Transition timing uses Quart EaseOut curves.

What This Looks Like in Code

The preview above is generated by this code:

lua 
local Window = KetamineUI:CreateWindow({
    Name = "Example Hub",
    Subtitle = "v1.0 | Interactive Demo"
})

local Combat = Window:CreateTab("Combat")
Combat:CreateSection("AIMBOT")
Combat:CreateToggle({Name = "Enable Aimbot", ...})
Combat:CreateSlider({Name = "FOV Radius", Min = 50, Max = 800, ...})
Combat:CreateSlider({Name = "Smoothness", Min = 0, Max = 100, ...})
Combat:CreateDropdown({Name = "Target Part", ...})

local Visuals = Window:CreateTab("Visuals")
-- ...

local Misc = Window:CreateTab("Misc")
-- ...
