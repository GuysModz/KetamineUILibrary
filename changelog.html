Changelog

Version history and release notes for KetamineUI.

v1.0 May 18, 2026 Latest
  • New Initial release of KetamineUI library
  • New Window system with draggable, minimizable frames
  • New Tab navigation with animated switching
  • New Toggle element with smooth knob animation
  • New Slider element with drag-to-adjust functionality
  • New Button element with hover and press effects
  • New Dropdown element with expandable option list
  • New Textbox element with Enter-to-submit
  • New Label element for dynamic status display
  • New Section headers for element grouping
  • New Notification system via Roblox CoreGui
  • New Customizable theme system (12 color properties)
  • New 7 premade UI themes (Default, Glass, Neon, Midnight, Rosé, Ember, Arctic)
  • New Keybind to toggle UI visibility (default: RightCtrl)
  • New Programmatic control via :Set() and :Get() methods
  • New Dropdown :Refresh() for dynamic option updates
  • New Auto-parent to CoreGui with PlayerGui fallback
  • New ResetOnSpawn = false for persistence through deaths

Roadmap

Planned features and improvements for upcoming versions.

🎨 Theme Presets API Planned

Pass theme name as a string instead of manually setting colors. e.g. Theme = "Neon"

⌨️ Keybind Element Planned

Allow users to bind custom keys to toggles and actions directly from the UI.

🖼️ Image Support Planned

Add image/icon support to tabs, buttons, and cards using Roblox asset IDs.

💾 Config Saving Planned

Auto-save toggle states, slider values, and selections to executor filesystem.

🔔 In-UI Notifications Planned

Toast notifications inside the UI window instead of relying on Roblox CoreGui.

📐 Multi-Column Layout Planned

Side-by-side element arrangement for wider windows.

🔍 Search / Filter Planned

Search bar to quickly find elements across all tabs.

📱 Mobile Optimization Planned

Touch-friendly controls, larger hit areas, and swipe gestures for mobile executors.
